# Ahorros L y V

Página web para seguir entre varias personas el ahorro para un viaje. Cada quien registra lo que lleva y todos ven el progreso hacia la meta en tiempo real.

🔗 **Ver en vivo:** https://ahorrosluisayvictor.netlify.app/

**Autor:** Victor Mendoza

**Contribudora:** [Luisa Triana](https://luisatriana.dev/) · [GitHub](https://github.com/lutriana)

## Qué hace

- Define el nombre de la meta y el monto a ahorrar.
- Agrega o quita personas y registra cuánto aporta cada una.
- Muestra el progreso total hacia la meta.
- Guarda un historial de metas anteriores.
- Sincroniza los datos en tiempo real entre todos los dispositivos.
- Botón para reiniciar el conteo.

## Tecnologías

- HTML, CSS y JavaScript separados en sus respectivos archivos
- Firebase Realtime Database para la sincronización
- Netlify para el despliegue

## Cómo usarlo localmente

Abre `ahorrolyv.html` en el navegador. Para usar tu propia base de datos, cambia el objeto `firebaseConfig` por el de tu proyecto de Firebase.
